# אדרה – סקיצה לחנות סרטים לפאה

סקיצה ראשונית לאתר-חנות. אתר סטטי (HTML/CSS/JS), בלי שרת ובלי התקנות.

## איך פותחים
פותחים את `index.html` בדפדפן.

## מה יש בסקיצה
- עמוד בית: מסר ראשי, יתרונות, חנות עם סינון לפי סוג ובחירת צבע
- חלון מוצר עם פרטים, וסל קניות (נשמר בדפדפן)
- "מה זה סרט לפאה", טבלת השוואה, "איך משתמשים" + מקום לסרטוני טיקטוק
- המלצות, סיפור העסק, שאלות נפוצות, צור קשר, כפתור וואטסאפ צף
- התאמה מלאה לנייד, RTL

## מה עוד לא אמיתי
- כל המוצרים, המחירים, הטקסטים וההמלצות הם **לדוגמה** (מסומנים בצהוב / באזורים מפוספסים)
- התשלום: כרגע ההזמנה נשלחת כהודעת וואטסאפ. מספר הוואטסאפ מוגדר ב-`app.js` (`WHATSAPP_NUMBER`)
- הקטלוג נמצא במערך `PRODUCTS` ב-`app.js`

לענות על השאלות ב-[QUESTIONS.md](QUESTIONS.md) ולשלוח קישורים לפייסבוק ולטיקטוק.
